# 外部片源渠道

本文件夹是「超越次元」的**唯一内容来源**：App 启动/自检时自动读取这里的 JSON，
首页、搜索、详情、分类、播放线路全部由这里的渠道提供。
**本版没有内置聚合片源，AGE 主站也已改为本文件夹里的 `AGE片源.json` 渠道。**
没有启用的渠道时，App 首页会显示「番剧源暂不可用」——启用任意一个渠道即可看到内容。

## 一、渠道文件格式

```json
{
  "name": "星空片源",
  "type": "maccms",
  "api": "https://host/api.php/provide/vod/",
  "mirrors": ["https://备用域名/api.php/provide/vod/"],
  "enabled": true
}
```

### 两种类型

| type | api 填什么 | 说明 |
| --- | --- | --- |
| `maccms` | `https://host/api.php/provide/vod/` | 苹果CMS10 JSON 接口，线路为直链（m3u8），播放走直链 |
| `age` | AGE 站点域名，如 `https://www.agefans.com` | AGE 动漫站抓取（复用原 AGE 实现），线路为站点原生线路，`mirrors` 填备用域名 |

## 二、字段说明

| 字段 | 说明 |
| --- | --- |
| name | 线路显示名称（App 线路列表里看到的名字） |
| type | `maccms` 或 `age`（缺省按 `maccms` 处理） |
| api | maccms 为资源站接口地址；age 为站点域名，必须以 `http://` 或 `https://` 开头 |
| mirrors | 备用镜像/备用域名，主域失联时自动切换（可留空数组） |
| enabled | `true` 启用 / `false` 停用 |

maccms 渠道要求接口支持：
- 列表：`?ac=list&wd=关键词`
- 详情：`?ac=detail&ids=ID`
返回标准 maccms JSON（`list` / `vod_play_url`）。

**只看动漫**：maccms 资源站大多是影视综合站（电影、电视剧、动漫混排）。
App 接入时会按分类名（动漫 / 番剧 / 动画 / 国漫 / 日漫 / 剧场版 / OVA 等）自动过滤，
首页、搜索、分类页都只会出现动漫条目，影视剧不会显示。

## 三、使用方式

1. 直接把符合格式的 `.json` 放到本文件夹，重启 App 或点「源修复 → 刷新列表」即可。
2. 也可以在 App 内操作：**我的 → 源修复 → 外部片源渠道**，填写名称/接口/镜像，添加、启停、编辑、删除。
3. 线路按渠道顺序排列（AGE 渠道的线路为站点原生线路，maccms 渠道为 x 直链线路）；增删渠道会改变编号。

## 四、安全说明

- 渠道文件**只包含接口地址**，不加载任何可执行代码（不读 `.py`、不执行脚本）。
- 本版没有内置片源，因此不存在"内置源被覆盖"的问题；删除本文件夹里的渠道文件即可移除该渠道。
- AGE 类型渠道不发起爬虫脚本，只按域名抓取公开页面（沿用 App 自带实现）。
- 请只添加你信任的资源站接口。

## 五、渠道清单

| 文件 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `AGE片源.json` | age | **启用** | AGE 动漫站点（agefans.com，自动切换备用域名），内容来源 |
| `非凡片源.json` | maccms | 启用 | 影视综合站，只接入日漫（国产/欧美/韩台动漫与影视剧均不显示） |
| `暴风片源.json` | maccms | 启用 | 影视综合站，只接入日漫（国产/欧美/韩台动漫与影视剧均不显示） |
| `量子片源.json` | maccms | 启用 | 影视综合站，只接入日漫（国产/欧美/韩台动漫与影视剧均不显示） |
| `红牛片源.json` | maccms | 启用 | 影视综合站，只接入日漫（国产/欧美/韩台动漫与影视剧均不显示） |
| `示例渠道.json` | maccms | 停用 | 格式模板，接口为 example.com，不会生效 |

只接入日漫：非日本地区的动漫（国产动漫、欧美动漫、港台动漫、韩国动漫）与影视剧都不会显示，日本动漫可正常浏览，同时作为 AGE 播放解析失败时的备用直链线路。
